## 🎯 Project Goals

This project serves dual purposes:

1. **Personal Health Tracking** - Fast, mobile-first symptom logging for MS management
2. **Learning Platform** - Professional development workflow and modern web technologies

Key principles:
- **5-second logging** during spasm episodes
- **Data privacy** with user-controlled Supabase instance
- **Professional workflow** with issues, feature branches, and code review
- **Modern tech stack** (SvelteKit, TypeScript, Supabase, Cloudflare)
